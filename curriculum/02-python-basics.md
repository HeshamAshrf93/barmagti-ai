# أساسيات بايثون: المتغيرات والشروط والتكرار

## المتغيرات (Variables)
المتغير هو اسم بنخزّن فيه قيمة في الذاكرة عشان نستخدمها بعدين. مثال: `age = 15` هنا المتغير age فيه القيمة 15.
أنواع البيانات الأساسية: int للأعداد الصحيحة، float للأعداد العشرية، str للنصوص، bool للقيم المنطقية True و False.
الدالة input() بتقرا من المستخدم وبترجّع نص، فلازم نحوّله لرقم بـ int() لو هنحسب بيه.

## الجمل الشرطية (if)
بنستخدم if عشان البرنامج ياخد قرار. مثال:
```python
if grade >= 50:
    print("ناجح")
else:
    print("راسب")
```
لازم نحط نقطتين : بعد الشرط، والسطر اللي جوه يكون عليه مسافة بادئة (indentation).

## التكرار (Loops)
حلقة for بتكرر عدد مرات معروف، مثال طباعة الأرقام من 1 لـ 5:
```python
for i in range(1, 6):
    print(i)
```
الدالة range(1, 6) بتبدأ من 1 وبتقف قبل 6.
حلقة while بتكرر طول ما الشرط صحيح، ولازم نغيّر المتغير جوه الحلقة عشان متبقاش لا نهائية.
